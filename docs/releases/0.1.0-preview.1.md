# AACpipe 0.1.0-preview.1

Experimental, unsigned Windows preview for trusted private networks and the AAC
device's own hotspot. No public publication is implied by these prepared notes.
Keep the normal AAC communication route available.

## Included

- Grid 3 bridge for word/sentence/speak/clear, auto-hiding the pairing window;
  explicit show/hide controls.
- Permanent and one-time pairing, unique labels, confirmed UI revocation and
  label-based commands.
- Stable `.local` discovery with named-adapter IP fallback QR codes.
- Simplified recommended pairing display, collapsed fallbacks, Copy link,
  refresh, original icons, About/version and privacy-filtered diagnostics.
- Optional partner TTS, beep and keep-awake controls.
- Session-capability management isolation in Electron; another ordinary
  loopback browser is no longer allowed to read/manage pairings.
- MIT licence, generated bundled third-party notices, installer checksum,
  updated dependency tooling, package smoke test and Windows artifact workflow.
- Upgrades from this preview onward preserve app data; normal uninstall removes it.

## Known limitations

- HTTP bootstrap is vulnerable to active network attackers. Do not use public
  Wi-Fi or expose the port to the internet. Authenticated transport is a future
  release gate, not a feature of this preview.
- Real Grid 3, Android/iPhone, hotspot and clean-VM install lifecycle tests
  remain pending; see [acceptance](../acceptance-tests.md).
- No Bluetooth, Wi-Fi Direct, hardware receiver firmware, internet relay or
  automatic address migration.
- mDNS/network restrictions may require IP fallback. Browser address changes
  require rescanning.
- Sound, TTS and wake depend on browser activation/background/silent-mode
  rules. Voice providers may use online processing.
- Upgrading from old `0.1.0` may reset existing pairings. Uninstalling deletes
  Windows pairing data. Pair again when needed.
- Eight moderate npm advisories remain in build-time packaging dependencies;
  no production npm advisories were reported in the reviewed lockfile.
